ARB 14-May-2024. Attendees: L. Fischer (chair), P. Okoye, S. Iyer, D. Mensah (Sec), K. Brandt, + 2 guests from the Data team.

AGENDA
1) Proposal: adopt a vector database for the internal knowledge search pilot
2) Retiring the legacy SFTP gateway
3) Observability standard

NOTES
1) Pilot "Ask Northwind": semantic search over SharePoint and Confluence. Data team proposes managed vector index vs pgvector in our existing Postgres. Concerns: security trimming (must honour SharePoint ACLs!), freshness of re-indexing, embedding model lock-in. Decision: approve a 6-week pilot using pgvector + BM25 hybrid; must include access-control filtering BEFORE ranking and a golden query set to measure quality. P. Okoye to own the evaluation.
   - Question from Sam: cost of re-embedding if we change model? Answer: negligible at this corpus size (~80k docs) but needs a versioned index.
2) SFTP gateway: 14 clients still use it; migration to the secure transfer service by Q4. Action: S. Iyer to contact the clients.
3) Observability: adopt OpenTelemetry for new services; existing services get a 12-month window.
